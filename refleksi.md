# Refleksi

# Platform yang Paling Menarik

Platform yang paling menarik bagi saya adalah mobile. Saya sangat suka membuat aplikasi mobile karena di zaman sekarang kita hampir tidak pernah jauh dari aplikasi, mulai dari memesan makanan, memesan driver online, berbelanja pakaian lewat Uniqlo, sampai mengambil nomor antrean rumah sakit. Impian saya adalah membuat aplikasi mobile yang memudahkan berbagai pihak dalam kehidupan sehari-hari.

# Tantangan Terbesar saat Setup

Tantangan terbesar saya adalah salah ketik (typo) saat menulis perintah di CMD maupun terminal VS Code. Selain itu, saat melakukan commit ke GitHub sempat muncul pesan "nothing to commit". Penyebabnya, file yang saya buat belum ada isinya dan sempat berada di folder yang salah, sehingga Git tidak mendeteksi perubahan. Saya juga sempat salah menamai repository karena ikut mengetik tanda kurung siku dari contoh di soal, sehingga namanya harus diubah lewat Settings.

# Rencana Mengatasinya

Ke depan saya akan lebih teliti dalam membaca instruksi dan memeriksa perintah sebelum menekan Enter. Saya juga akan mengecek lokasi folder dan menjalankan git status sebelum commit. Saat terjadi error, saya akan membaca pesan kesalahannya dengan tenang, baik di program maupun di kode yang saya tulis, supaya bisa menemukan penyebabnya. Dengan begitu saya bisa lebih teliti dalam menulis program.
